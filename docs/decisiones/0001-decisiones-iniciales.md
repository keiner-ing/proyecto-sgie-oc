# ADR 0001 — Base de desarrollo

- **Estado:** propuesto
- **Contexto:** crear proyecto-sgie con OpenCode 2, VS Code, Git y CI.
- **Decisión:** usar el perfil inicial `web` como punto de partida, ajustable conforme a requisitos.
- **Consecuencias:** tests, reglas y revisiones en repositorio; extensiones y base de datos se elegirán según necesidad.
